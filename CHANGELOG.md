# Changelog

## Open-source release

- BatchCrop is now free and open source under the MIT license.
- The plugin code is unchanged from 1.0.1. The crop overlay icons are not included; the overlay tools were never finished and have no UI.

## 1.0.1

- Batch crop images with preset/custom aspect ratios (1:1, 9:16, 4:5, etc.)
- Add/remove ratios, auto/manual crop mode
- Choose JPG/PNG, set output folder
- Progress bar, responsive UI, error handling
- Welcome/done modals, modern dark styling
- Overlay tools (prepared)
- Reset/reload via menu
